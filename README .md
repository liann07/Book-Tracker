# Book Tracker

A reading log app to track the books you want to read, are reading, or have finished. It works on Android and iPhone, can be installed on the home screen, and works offline.

**Live app:** https://tiny-semifreddo-fe25fe.netlify.app

## Features
- Add books with title, author, main genre, sub genre, source and status
- Bookshelf view with colored book spines
- Reading stats: on the shelf, reading now, finished and waiting
- Search by title, author or genre
- Filter by status
- Edit and remove books, with a confirmation message
- Light and dark mode
- Installable and works offline (Progressive Web App)

## Technologies
- HTML, CSS and JavaScript
- localStorage to save books on the device
- Service worker and web manifest for offline use and installation
- GitHub, Netlify and GitHub Pages for hosting

## How to run
1. Download or clone this repository.
2. Open `index.html` in a browser (or use the Live Preview extension in VS Code).
